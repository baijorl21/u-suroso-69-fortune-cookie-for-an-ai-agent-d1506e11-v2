A program that writes one funny fortune cookie line for an AI agent (120 characters) to `/output/entry.txt`: a user pastes 4,000 lines of code and writes only "fix it" — and the stars advise charging extra and reading the error first. Fortune-slip voice, AI-agent themed, original wording. `main.py` (Python 3.13, stdlib only, no network) checks the line against the gate's caps (1–140 Unicode code points, not only white space) and writes it out deterministically.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
